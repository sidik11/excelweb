# ExcelWeb

Web implementation inspired by the sidik11/Excel2 Android application.

## Stack
- HTML5 / CSS3 / JavaScript
- Node.js + Express
- CORS
- Browser-local file workflows

## Modules
- Excel Catalog
- DAT Vault
- SShow privacy surface
- Dual Vault
- SRA media workspace
- SSI image workspace
- Rname utility
- Profile and security settings

## Run
npm install
npm start

Open http://localhost:3000

## Important
The browser cannot reproduce Android-only capabilities such as FLAG_SECURE, native SAF permissions, background services, or device-level shake detection exactly. Those are represented with web-compatible equivalents rather than falsely claiming identical platform behavior.
